# Город рядом — гид по Кишинёву

Твой гид по Кишинёву: места с характером, прогулки без спешки и маленькие открытия — собрали город таким, каким его любят местные.

Деплой: [gorod-ryadom-chisinau.vercel.app](https://gorod-ryadom-chisinau.vercel.app/)

## Стек технологий
- HTML5 / CSS3 / Vanilla JavaScript (ES6+)
- Supabase (авторизация, отзывы, оценки, фото)
- Google Maps Embed API
- Хостинг: Vercel
